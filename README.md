Aplikasi AR Berbasis Marker

Aplikasi Augmented Reality (AR) sederhana yang mampu mendeteksi gambar marker kustom dan menampilkan objek 3D secara real-time melalui webcam.

Framework AR: MindAR (WebAR)
Rendering 3D: A-Frame
Platform: Browser-based

Aplikasi ini dibuat alternatifdari Unity dan Vuforia karena adanya kendala saat penginstalan dan kompabilitas perangkat yang digunakan
